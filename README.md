# WARP-конфиг для AmneziaWG — своими руками

Как сделать конфиг WARP для AmneziaWG, чтоб работал интернет (особенно иностранные сервисы).

P.s Данный метод меняет IP (но НЕ на иностранный) так что сервисы которые блокируют доступ по регионам (РФ,Белорусь и т.д) все также не доступны без смены региона

## Что понадобится

- Прямые руки
- Windows (на других ОС примерно так же)
- Приложение AmneziaWG
- Бесплатный ключ из Cloudflare One Client

## P.S Для ленивых

Пишем в поисковик `генератор конфигов amneziaWG\warp` и тому подобное.

Сайты для генерации конфигов:

https://valokda-amnezia.vercel.app/

https://warp-gen.github.io/

(или любые другие)

Открываем AmneziaWG, жмём `+`, выбираем **«Импорт из файла»** и указываем путь к конфигу.

## 1. Качаем Cloudflare WARP

Ссылка: https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/

Либо просто гуглим «Cloudflare WARP» и качаем оттуда. (забанен в РФ)

## 2. Ставим и выбираем версию

При установке дают два варианта:

- **1.1.1.1 with WARP** — обычная повседневная версия
- **Cloudflare One Client** — корпоративная штука

Нам нужен **1.1.1.1 with WARP**. (там будет ключ)

## 3. Достаём ключ

Открываем приложение, идём во вкладку **«Профиль»** — там будет ваш лицензионный ключ. Копируем его куда-нибудь, скоро пригодится.

## 4. Качаем amneziaWG

Страница релизов: https://github.com/amnezia-vpn/amneziawg-windows-client/releases

## 5. Качаем wgcf 

Это утилита, которая нам всё сгенерирует.

Страница релизов: https://github.com/ViRb3/wgcf/releases

Выбираем версию под Windows (например, `wgcf_xxx_windows_amd64.exe`).

Для удобства:
- Создаём где-нибудь папку, например `C:\wgcf`
- Кидаем скачанный файл туда
- Переименовываем в `wgcf.exe` (просто чтобы короче было)

## 6. Открываем командную строку

Жмём `Win + R`, пишем `cmd`, ОК.

Заходим в нашу папку:
```cmd
cd C:\wgcf
```
## 7. Регистрируем аккаунт

```cmd
wgcf register
```
и нажимаем enter (согласие с условиями cloudflare) также нужен доступ к серверам, так как выдаст ошибку при согласии

[гайд по доступу к серверам cloudflare с помощью Zapret](https://github.com/niksus23/-cloudflare-Zapret/tree/main)

## 8. Вписываем ключ

После регистрации в папке появится файл `wgcf-account.toml`.

Открываем его Блокнотом, ищем строку:

license_key = ""

Между кавычек вставляем тот самый ключ из Cloudflare One Client.

## 9. Привязываем ключ
```cmd
wgcf update
```
## 10. Генерируем конфиг
```cmd
wgcf generate
```
в папке появился файл wgcf-profile.conf — это наш будущий конфиг для AmneziaWG.

---

## 11. Импортируем в AmneziaWG

Открываем AmneziaWG, жмём `+`, выбираем **«Импорт из файла»** и указываем путь к `wgcf-profile.conf`.

## 12. Меняем Endpoint (если обычный не работает)

В AmneziaWG жмём **«Редактировать»** на нашем туннеле и ищем строку `Endpoint`.
```ini
engage.cloudflareclient.com:2408

8.47.69.0:1002

188.114.99.224:1002

162.159.193.0:2408

8.47.69.122:988

8.47.69.20:1074

8.39.125.147:854

8.47.69.12:7156

188.114.96.239:1387
```
и тому подобные. 

[Гайд по поиску рабочих endpoint](https://github.com/niksus23/Endpoint-AmneziaWG)

## 13. Добавляем обфускацию

В том же редакторе конфига находим секцию `[Interface]` и добавляем/проверяем:

```ini
Jc = 4

Jmin = 40

Jmax = 70
```
**подмена заголовков WireGuard**
```ini
H1 = 1

H2 = 2

H3 = 3

H4 = 4
```
**начальные пакеты для обфускации handshake**
```ini
I1 = <b 0x494...>
```
**DNS и MTU**
```ini
DNS = 1.1.1.1, 1.0.0.1

MTU = 1280
```
## Пример готового конфига

```ini
[Interface]
PrivateKey = ...ваш приватный ключ...
Jc = 4
Jmin = 40
Jmax = 70
H1 = 1
H2 = 2
H3 = 3
H4 = 4
I1 = <b 0x494...>
Address = 172.16.0.2/32
DNS = 1.1.1.1, 1.0.0.1
MTU = 1280

[Peer]
PublicKey = ...публичный ключ...=
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint = engage.cloudflareclient.com:2408
```
---
## Если сайты не грузятся

1. Меняйте `Endpoint` на другой из списка в шаге 11
2. Отключайте и заново включайте туннель
3. Иногда помогает просто перегенерировать конфиг заново
4. поменяйте I1
5. измените значения Jc, Jmin, Jmax
